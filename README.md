# Portfolio d’Evens THÈS

Identités visuelles, affiches, développement web et formation.

Site statique en français, avec galerie filtrable, présentation du projet iGH, parcours et photo personnelle. Le projet iGH inclut un badge en version publique. Un bouton WhatsApp ouvre une discussion avec message préparé.

## Utilisation
Ouvrir `index.html` dans un navigateur. Aucune installation ni compilation nécessaire.

## Publication
GitHub Pages : branche `main`, dossier racine `/`. Le fichier `.nojekyll` désactive Jekyll.

## Personnalisation
- `configuration.js` : photo de profil, numéro WhatsApp et message préparé.
- `projets.js` : catalogue des réalisations.
- `index.html` et `projet-igh.html` : pages.
- `style.css` : présentation.

Le formulaire prépare un e-mail dans la messagerie du visiteur. Aucun message n’est envoyé automatiquement.

Les créations et images restent soumises aux droits de leurs auteurs respectifs.
