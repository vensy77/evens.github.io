# Portfolio d’Evens THÈS

Identités visuelles, affiches, développement web et formation.

Site statique en français, avec galerie filtrable, présentation des projets iGH, KAYATIS, Lasol et Stanley Jean Louis, parcours et photo personnelle. Le projet iGH inclut un badge en version publique. Le projet KAYATIS regroupe son logo et deux affiches de formation. Un bouton WhatsApp ouvre une discussion avec message préparé.

## Utilisation
Ouvrir `index.html` dans un navigateur. Aucune installation ni compilation nécessaire.

## Publication
GitHub Pages : branche `main`, dossier racine `/`. Le fichier `.nojekyll` désactive Jekyll.

## Personnalisation
- `configuration.js` : photo de profil, numéro WhatsApp et message préparé.
- `projets.js` : catalogue des réalisations.
- `index.html`, `projet-igh.html` et `projet-kayatis.html`, `projet-lasol.html` et `projet-stanley.html` : pages.
- `style.css` : présentation.

Le formulaire prépare un e-mail dans la messagerie du visiteur. Aucun message n’est envoyé automatiquement.

Les créations et images restent soumises aux droits de leurs auteurs respectifs.

Le catalogue regroupe 21 projets : 10 identités visuelles, 8 projets d’affiches et 3 projets de cartes et supports. Les visuels d’un même projet peuvent être réunis sur une page dédiée. Les images optionnelles `image` et `thumbnail` dans projets.js permettent de choisir le visuel principal et sa miniature.
